# Data

This directory contains the datasets used by the project.

## Raw data

Place the original OSMI Mental Health in Tech 2016 survey dataset in:

```text
data/raw/
```

Raw data should not be modified.

## Processed Data

Intermediate datasets created during the data-preparation workflow belonging in:

```text
data/processed/
```

Processed datasets should be reproducible from the raw dataset and the project's documented preprocessing workflow.

## Dataset source

The project uses the OSMI Mental Health in Tech 2016 survey dataset:

https://www.kaggle.com/osmi/mental-health-in-tech-2016

The repository should document the dataset source, acquisition date, file name, and relevant licensing or usage conditions rather than embedding third-party dataset ownership claims in the project.
